# Imagen destacada de la portada

Para poner un banner en la portada, sube aquí un archivo llamado **exactamente** `destacada` (con `.jpg`, `.png` o `.webp`).

- Archivo: `destacada.jpg` (o `.png`, `.webp`).
- En GitHub: **Add file → Upload files**, arrastra la imagen y pulsa **Commit changes**. El sitio se actualiza solo en unos minutos.
- Solo puede haber una. Si subes otra con el mismo nombre, reemplaza a la anterior.

Notas:
- Sube imágenes propias del equipo (ilustraciones, fotos tuyas). No subas fotos de terceros sin permiso.
- Ideal: al menos 1600 px de ancho y menos de 4 MB. El sitio la convierte a WebP ligero.
- Si borras el archivo, la portada vuelve a verse como antes (sin banner).
