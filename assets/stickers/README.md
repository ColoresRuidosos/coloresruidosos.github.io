# Stickers

Para agregar un sticker a `/stickers/`, sube aquí el archivo de imagen.

- Formatos: `.png`, `.webp` o `.svg` (los dos primeros con fondo transparente se ven mejor). También sirven `.jpg` y `.avif`.
- El nombre que se muestra sale del nombre del archivo: `sticker-toronjo.png` se muestra como "Sticker toronjo".
- En GitHub: **Add file → Upload files**, arrastra la imagen y pulsa **Commit changes**. El sitio se actualiza solo en unos minutos.

Notas:
- Solo stickers propios del equipo (diseños o ilustraciones suyas). No subas stickers o imágenes de terceros sin permiso.
- Ideal: al menos 640 px de ancho, formato cuadrado o con espacio alrededor, menos de 2 MB. El sitio convierte PNG/JPG a WebP; SVG se usa tal cual.
- Al pasar el cursor (o tocar en celular) cada sticker brilla con un efecto holográfico.
- Si borras el archivo, el sticker desaparece de la galería.
