# Arde la Torre (título provisional)

Beat 'em up cooperativo para hasta 4 jugadores, homenaje no oficial de Colores Ruidosos a **Arde Bogotá**: la banda sube la Torre Picasso planta a planta. Se juega en una pantalla compartida (tele, portátil o tablet) y **cada jugador usa su móvil como mando** escaneando un QR.

**Estado:** especificación en borrador; todavía no hay código.
